# Figshare 铁氰化物/亚铁氰化物 CV（4 条）

- 数据页：https://figshare.com/articles/dataset/19603363
- DOI：https://doi.org/10.6084/m9.figshare.19603363.v3
- 许可证：CC BY 4.0
- 体系：5.0 mM `[Fe(CN)6]3−/4−`，0.1 M KCl
- 扫描速率：50 mV s−1
- 仪器：CHI 760D

四条曲线分别来自裸碳糊电极、ZnO NPs-CPE、poly(glutamic acid)/CPE 和 poly(glutamic acid)/ZnO NPs-CPE。每条曲线均包含从 −0.2 V 到 0.8 V 再返回的完整往返扫描、区间内部的阳极正峰和阴极负峰，是本轮新增数据中最接近参考示意图的一组。

根目录中的 CSV 为统一后的三列数据：`Sequence, Potential_V, Current_A`。`original_txt/` 保存 Figshare 发布的 CHI 文本文件；原文件头标记 `Data Proc: Smoothing`。本文件夹中的绘图没有再做平滑或基线校正。
